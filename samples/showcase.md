# mdcat Showcase

이 문서는 **mdcat**이 지원하는 거의 모든 마크다운 요소를 한 번에 보여줍니다.
색·배경·폰트는 터미널 기본값을 그대로 따르고, 제목만 kitty OSC 66으로 크게 그립니다.

## 1. 인라인 스타일

한 문단 안에서 **굵게**, *기울임*, ***굵은 기울임***, `인라인 코드`,
~~취소선~~, 그리고 [링크](https://example.com)를 섞어 쓸 수 있습니다.
긴 문단은 터미널 폭에 맞춰 자동으로 줄바꿈됩니다 — 창 크기를 바꿔 보면
가로가 다시 꽉 차도록 다시 배치되는 걸 볼 수 있어요.

## 6. 코드 블록 (여러 언어)

Rust:

```rust
fn main() {
    let msg = "hello, mdcat";
    for i in 0..3 {
        println!("{i}: {msg}");
    }
}
```

Python:

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("mdcat"))
```

Shell:

```bash
mdcat README.md

```
