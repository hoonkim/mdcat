# mdcat — kitty 기반 마크다운 뷰어 설계

작성일: 2026-06-22
상태: 승인됨 (구현 계획 작성 단계로 진행)

## 개요

`mdcat <파일.md>` 로 마크다운 파일을 전체화면 페이저(터미널 alternate screen)에서
렌더링하는 Rust CLI. kitty 터미널 전용으로 시작하며, 두 가지 kitty 프로토콜을 사용한다.

- **텍스트 크기 조정 프로토콜 (OSC 66)** — 제목을 크게 표시
- **그래픽 프로토콜** — 마크다운에 포함된 이미지 표시

본문은 실제 터미널 텍스트로 출력하므로 색/배경/폰트는 터미널 기본값을 그대로 상속한다
(자체 색 지정을 최소화하고 ANSI 기본 팔레트만 사용). 가로는 터미널 폭에 맞춰 꽉 채우고
본문은 폭에 맞게 워드랩한다. `q` 종료 시 alternate screen을 복원한다.

## 동작 (UX)

- 실행: `mdcat <path>`
- 키/마우스:
  - 마우스 휠: 위/아래 스크롤 (1틱 = 약 3행)
  - `j` / `k`: 한 행 아래/위
  - `Space` / `b`: 한 페이지 아래/위
  - `g` / `G`: 처음/끝으로
  - `q` 또는 `Ctrl-C`: 종료
- 리사이즈(SIGWINCH): 재레이아웃, 스크롤 오프셋을 비율로 보정
- 가로: 터미널 폭에 맞춤. 본문은 콘텐츠 폭(폭 - 좌우 여백)으로 워드랩

## 아키텍처 (모듈)

각 모듈은 하나의 명확한 책임을 가지며 인터페이스로 통신한다.

- `cli` — 인자 파싱(`<path>`), 파일 읽기, 사용자 대상 에러 처리
- `parser` — `pulldown-cmark` 이벤트를 중간 표현(IR) `Block` 트리로 변환
  (문단/제목/리스트/코드블록/표/이미지/인용/수평선 등). 터미널/렌더링과 무관한 순수 변환.
- `layout` — 현재 터미널 폭 기준으로 `Block` 들을 **렌더 행(row) 시퀀스**로 배치.
  각 블록은 자신의 **터미널 행 단위 높이**를 알고, 주어진 세로 클립 범위를 그리는 방법을 안다.
  워드랩, 표 폭 분배, 제목 스케일 폭 계산이 여기 들어간다. 순수 함수 위주 → 단위 테스트 대상.
- `render` — 행을 실제 이스케이프 시퀀스로 출력.
  인라인 스타일(굵게/기울임/인라인코드/링크), 제목(OSC 66), 코드(syntect), 표(박스 드로잉),
  이미지(kitty 그래픽 프로토콜).
- `pager` — alternate screen + raw mode, `scroll_offset`(터미널 행 단위) 관리, 입력 루프,
  리사이즈 처리, 프레임 그리기.
- `term` — 터미널 크기 및 셀 픽셀 크기 조회(ioctl `TIOCGWINSZ`의 `ws_xpixel`/`ws_ypixel`),
  기능 감지.

## 렌더링 모델

### 본문 (인라인)
실제 터미널 텍스트로 출력. ANSI SGR만 사용하고 색 지정은 최소화하여 터미널 기본색을 상속한다.
- 굵게 = `1m`, 기울임 = `3m`, 인라인 코드 = 흐리게/반전, 링크 = 밑줄(`4m`)
- 인용(`>`)은 좌측 `│` 마커 + 들여쓰기
- 리스트는 들여쓰기 + 불릿/번호

### 제목 (OSC 66 텍스트 크기 조정)
형식: `\x1b]66;<metadata>;<text>\x1b\\` (종결자 `BEL` 또는 `ESC \`).
- `s` = 정수 스케일(1–7), `n`/`d` = 분수 스케일 분자/분모
- 매핑: H1=`s=2`(2.0x), H2=`n=3,d=2`(1.5x), H3=`n=5,d=4`(1.25x), H4–H6=`s=1` + 굵게
- 스케일 시 글자가 **가로로도** 커지므로 (s=2면 글자당 2셀 폭, 2행 높이),
  제목의 워드랩 가능 폭 = `content_cols / scale`, 높이 = `ceil(scale)` 행으로 계산
- 페이로드 4096바이트 제한 → 긴 제목은 분할 전송. 화면보다 큰 멀티셀 블록은 폐기되므로
  스케일 후 폭이 화면을 넘으면 더 작은 스케일로 폴백

### 코드 블록
syntect로 토큰화하여 ANSI(트루컬러 또는 256색) 전경색을 입힌다. fence 언어 인식.
배경은 터미널 기본을 유지하고 전경색만 적용한다.

### 이미지 (kitty 그래픽 프로토콜)
- 소스: 로컬 경로 + `http(s)` URL 다운로드(`ureq`)
- 포맷: PNG는 그대로 전송(`f=100`), 그 외는 `image` 크레이트로 RGBA 디코드 후 전송(`f=32`)
- 페이로드는 base64로 청크 분할 전송
- 표시 크기: 셀 픽셀 크기를 기준으로 가로는 콘텐츠 폭에 맞추고 원본 비율을 유지하여 높이(행 수) 산정

## 스크롤 (핵심)

- 스크롤 단위는 **터미널 행**. 페이저가 `scroll_offset`(행)을 들고 매 프레임 보이는 행만 그린다.
- 레이아웃이 만든 블록 리스트를 순회하며 뷰포트에 보이는 구간만 출력.
  텍스트/코드/표는 줄 단위 클립이 자연스럽다.
- **세로로 잘리는 큰 요소**:
  - 이미지: 그래픽 프로토콜의 소스 크롭(`y`,`h`)으로 부분 표시 → 부드럽게 스크롤
  - 크기 조정된 제목: 글리프 세로 클립 불가 → **원자 단위**(전체 높이를 한 번에 그림)로 처리.
    뷰포트 상단에서 부분적으로 가려지는 프레임에서는 해당 제목 영역을 빈 행으로 둔다.
- 트레이드오프(v1 명시): 본문·코드·표·이미지는 매끄럽게 스크롤되지만,
  크기 조정된 제목은 경계에서 약간 튄다(픽셀 단위 부분 스크롤 불가).
- 마우스 휠 1틱 = 3행(상수로 조정 가능). 리사이즈 시 오프셋을 비율로 보정.

## 표

- `pulldown-cmark` 테이블 확장 사용
- 열별 콘텐츠 최대 폭 계산 → 콘텐츠 폭에 맞춰 분배(긴 셀은 워드랩),
  정렬(left/center/right) 반영
- 유니코드 박스 드로잉(`┌─┬┐│├┤└┘`)으로 테두리. 색/폰트는 터미널 기본 유지
- 폭 초과 시 열 폭을 비율로 축소

## 의존성

- `pulldown-cmark` — 마크다운 파싱 + 표/취소선/태스크리스트 확장
- `crossterm` — raw mode, alternate screen, 입력(키/마우스), 리사이즈 이벤트
- `syntect` — 코드 블록 신택스 하이라이팅
- `image` — 이미지 디코드(비PNG → RGBA)
- `ureq` — 원격 이미지 다운로드(blocking, 경량)
- `unicode-width` — 셀 폭 계산(CJK/이모지)
- `base64` — 그래픽 프로토콜 페이로드 인코딩

그래픽 프로토콜과 OSC 66 이스케이프는 직접 작성한다.

## 테스트 전략

- `layout`(워드랩, 표 폭 분배, 제목 스케일 폭/높이 계산)은 순수 함수로 분리해 단위 테스트(TDD)
- `render`는 이스케이프 출력 문자열 스냅샷 검증
- `pager`/그래픽 출력은 샘플 `.md`로 수동 육안 확인
